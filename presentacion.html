Sabor Norteno

Proyecto Final — Desarrollo Web Flex | Coderhouse

El presente proyecto consiste en el desarrollo de un sitio web institucional para "Sabor Norteno", un restaurante de comida regional del norte argentino ubicado en Salta Capital. El sitio fue desarrollado como proyecto final del curso de Desarrollo Web Flex de Coderhouse, aplicando HTML semantico, SASS, Bootstrap, responsive design y deploy en servidor.

El sitio esta dirigido a comensales locales y turistas que buscan autentica gastronomia nortena. La identidad visual fue construida con una paleta de marron tierra, chocolate y dorado que refleja calidez, tradicion y autenticidad, acompanada de tipografia Georgia para los titulos.

Estructura HTML

El sitio esta compuesto por 5 archivos HTML: index.html en la raiz del proyecto y cuatro paginas secundarias dentro de la carpeta pages/.

Todas las paginas comparten la misma estructura semantica con <header>, <nav>, <main>, <section> y <footer>, y estan interconectadas a traves del navbar.

  • 📄 index.html (Inicio)
  • 📄 pages/menu.html
  • 📄 pages/nosotros.html
  • 📄 pages/reservas.html
  • 📄 pages/contacto.html

Se utilizaron etiquetas semanticas como <article>, <section>, <header>, <footer> y <nav>. Cada pagina incluye meta tags de description y keywords para SEO.

SEO y Semantica

Se aplicaron meta tags y protocolos de optimizacion en todas las paginas del sitio:

Meta Description

Descripcion unica por pagina para buscadores

<meta name="description" content="Sabor Norteno - Restaurante de comida regional...">

Meta Keywords

Palabras clave relevantes por seccion

<meta name="keywords" content="restaurante, comida nortena, Salta, empanadas...">

Open Graph

Protocolo para compartir en redes sociales

<meta property="og:title" content="Sabor Norteno">
<meta property="og:description" content="...">
<meta property="og:type" content="website">

Etiquetas Semanticas

Estructura accesible y legible para crawlers

<header>, <nav>, <main>, <section>, <article>, <footer>

Accesibilidad

Atributos alt, aria-label, roles

<img alt="Empanadas saltenas" loading="lazy">
<button aria-label="Abrir menu">

Performance

Carga diferida y optimizacion

loading="lazy" en imagenes
CSS/JS via CDN con compresion
Imagenes optimizadas (Unsplash w=600)

Estilos SASS — Variables, Mixins y Extend

🎨 Variables

Paleta de colores, tipografia, espaciado y breakpoints centralizados en _variables.scss

🔨 Mixins

flex-center, heading-style, button-style, overlay, card-style, responsive()

📂 Nesting

Selectores jerarquicos con metodologia BEM (.card-plato__title, .footer__links)

🔁 @extend

Placeholder %section-padding compartido entre 7 secciones

📁 Partials

7 archivos parciales importados con @import en main.scss

scss/
├── main.scss
├── _variables.scss
├── _mixins.scss
├── _base.scss
├── _header.scss
├── _footer.scss
├── _home.scss
└── _pages.scss 
// _variables.scss
$color-primary: #8B4513;
$color-accent: #DAA520;
$color-dark: #2C1810;
$font-heading: 'Georgia', serif;

// _mixins.scss
@mixin responsive($breakpoint) {
  @if $breakpoint == md {
    @media (max-width: 767.98px) {
      @content;
    }
  }
}

@mixin button-style($bg, $text) {
  padding: 12px 32px;
  background-color: $bg;
  color: $text;
  border-radius: 8px;
  transition: all 0.3s ease;
  &:hover {
    transform: translateY(-2px);
    box-shadow: 0 4px 16px rgba(0,0,0,0.12);
  }
}

// _home.scss (nesting + extend)
.hero {
  @include flex-center;
  height: 100vh;
  background-attachment: fixed;

  &__title {
    @include heading-style(4rem);
    color: $color-white;
    animation: tracking-in-expand 0.8s;
  }

  &__subtitle {
    color: rgba(white, 0.9);
    font-style: italic;
  }

  @include responsive(md) {
    background-attachment: scroll;
  }
}

.bienvenida {
  @extend %section-padding;
}

Reflexion Final

Este proyecto represento mi primer desarrollo web completo aplicando todo lo aprendido en el curso de Desarrollo Web Flex de Coderhouse. Las principales dificultades que encontre fueron la organizacion de los archivos SASS con partials y la correcta implementacion de mixins y @extend, ademas de lograr que el navbar de Bootstrap quedara personalizado con la identidad visual del restaurante sin que se vean los estilos genericos del framework.

A lo largo del desarrollo aprendi a organizar un proyecto desde cero con una estructura de carpetas prolija, a trabajar con Git de forma incremental con commits descriptivos, y a publicar un sitio en Vercel conectado a GitHub. Tambien incorpore buenas practicas de SEO, accesibilidad y responsive design que me van a servir en futuros proyectos profesionales.

Me llevo la experiencia de haber construido algo funcional y visualmente atractivo que demuestra la aplicacion de HTML semantico, SASS avanzado, Bootstrap personalizado y deploy en servidor.
